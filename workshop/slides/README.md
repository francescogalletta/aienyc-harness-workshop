# Workshop slides

`deck.html` is the deck for the session: one self-contained page, no build step.
Open it in a browser.

| Key | Does |
| --- | --- |
| Right arrow, Space, click on the right | Next step or slide |
| Left arrow, click on the left | Back |
| `F` | Fullscreen |
| `D` | Light or dark |
| `#12` at the end of the address | Open at slide 12 |

Each slide is one `<section class="slide">` with a numbered comment above it;
the words are in the HTML. Dashed boxes are placeholders still to fill
(`data-placeholder`). The fonts load from Google Fonts and fall back to system
fonts offline.

The harness never uses this folder.
