# Saved reference terms

`terms.json` holds standard personal finance terms, each with a short
definition and the page it was checked against. The `reference` researcher
answers from this file, so the grounding interview can run offline and gives
the same answer every time.

Each source was opened and checked on 9 October 2026. To add a term, add an
entry with `term`, `aliases`, `definition` and `sources`. A lookup matches the
term or one of its aliases, ignoring case and hyphens.
